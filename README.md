## Для чого цей проєкт

- Навчання: допомагає школярам і початківцям зрозуміти, як працюють моделі розпізнавання поз і як їх застосовувати.
- Демонстрація: показує, як поєднувати MediaPipe та інші інструменти для створення інтерактивних GUI‑додатків.
- Прототипування: дозволяє швидко записувати та тестувати нові жести і поведінки завдяки вбудованій студії.
- Експерименти: дає простий спосіб збирати приклади жестів, налаштовувати пороги і вивчати різні парадигми.

## ✨ Основні можливості

- **⚡ On-Demand AI Architecture**: моделі MediaPipe (Face Landmarker, Hand Landmarker, Pose Landmarker) завантажуються в пам'ять лише за потреби.
- **🎨 Glassmorphism GUI (Flet)**:
  - Сучасний адаптивний інтерфейс на базі Flutter/Flet (Material 3).
  - Підтримка темної, світлої та системної тем із вибором з кількох акцентних кольорів.
  - Анімовані ефекти та плавні переходи.
  - **Працює як десктопний додаток або у веб‑браузері (`--web`)**.
- **🎯 6 базових парадигм жестів**:
  1. **Статична поза (Static Pose)** — фіксація форми кисті або нахилу голови (пальці стиснуті, знак миру ✌️, палець вгору).
  2. **Траєкторія руху (Spatial Trajectory)** — динамічний просторовий жест (змах рукою, коло, свайп).
  3. **Трансформація (Pose Transition)** — двоетапний жест: Поза A → Поза B (з таймером або затримкою).
  4. **Циклічний рух (Periodic Wave)** — повторюваний рух (махання рукою чи похитування головою).
  5. **Утримання пози (Hold Pose)** — утримання пози протягом заданого часу (1–5 с) з індикатором прогресу.
  6. **Аналоговий регулятор (Continuous Slider)** — плавне керування величиною (0%–100%) залежно від висоти або положення руки.
- **🔴 Вбудована студія запису жестів (`record_pose.py`)**: запис нових еталонів жестів безпосередньо з камери.
- **🧪 Жива перевірка жестів (`test_gesture.py`)**: швидке тестування з HUD‑індикацією і прогрес‑баром.
- **🔌 Модульність Hot‑Plug**:
  - `modules/gestures/` — додавання алгоритмічних `.py` модулів або збережених `.json` зразків.
  - `modules/actions/` — дії на спрацювання (емуляція натискання клавіш, звуковий сигнал, HUD‑повідомлення).
  - `modules/sources/` — джерела відео (вебкамера, відеофайли).

## 🚀 Швидкий старт

### 1. Клонування та встановлення залежностей

```bash
git clone https://github.com/Mazqwertyuio/pose_detector.git
cd pose_detector

# Створення віртуального середовища (рекомендовано)
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/macOS

# Встановлення пакетів
pip install -r requirements.txt
```

> **Примітка:** моделі MediaPipe (`.task`) автоматично завантажуються в папку `models_cache/` під час першого запуску.

---

### 2. Запуск

#### 🖥️ Графічний інтерфейс (Десктоп):
```bash
python flet_app.py
# або
python run.py --gui
```

#### 🌐 Веб‑версія у браузері (Web Studio):
```bash
python flet_app.py --web
# або
python run.py --web
```
*За замовчуванням відкривається локальний сервер на `http://localhost:8550`.*

Можна вказати власний порт і хост для доступу з іншого пристрою в локальній мережі:
```bash
python flet_app.py --web --port 8080 --host 0.0.0.0
```

#### 💻 Інтерактивне консольне меню:
```bash
python run.py
```
```text
ГОЛОВНЕ МЕНЮ:
  [1] Запустити розпізнавання (обрати джерело та рухи)
  [2] Записати новий рух / позу з камери (Record Pose)
  [3] Видалити записаний рух (Delete Gesture)
  [4] Запустити збережений пайплайн (pipeline.yaml)
  [5] Запустити графічний інтерфейс Flet (GUI Studio - Десктоп)
  [6] Запустити веб-версію у браузері (Web Studio - Браузер)
  [0] Вихід
```

## 📂 Структура проєкту

```text
├── core/                        # Ядро конвеєра
│   ├── engine.py                # Головний цикл обробки кадрів, дзеркалення, FPS
│   ├── model_manager.py         # Керування моделями MediaPipe Tasks (Lazy Loading)
│   ├── module_loader.py         # Динамічне завантаження модулів .py та .json
│   ├── template_detector.py     # Детектор 6 парадигм жестів за еталонами
│   ├── visualizer.py            # Візуалізація точок скелета, HUD та банерів
│   ├── wizard.py                # Інтерактивний консольний майстер налаштування
│   └── delete_manager.py        # Менеджер видалення зразків жестів
├── modules/
│   ├── gestures/                # Модулі розпізнавання жестів (.py)
│   │   └── recorded/            # Записані зразки жестів (.json)
│   ├── actions/                 # Дії на спрацювання (keyboard_press, sound_beep...)
│   └── sources/                 # Джерела кадрів (webcam, video_file)
├── utils/
│   └── pose_math.py             # Векторна геометрія: кути, нормалізація, відстані
├── flet_app.py                  # Повнофункціональна студія на Flet (Desktop & Web)
├── record_pose.py               # Консольна та інтерактивна утиліта запису жестів
├── test_gesture.py              # Автономний швидкий тест будь-якого жесту наживо
├── run.py                       # Головна точка входу для консолі та меню
├── pipeline.yaml                # Конфігурація збереженого конвеєра
└── requirements.txt             # Залежності проєкту
```

## ⌨️ Гарячі клавіші в додатку

- `Ctrl + 1 ... 5` — швидке перемикання між вкладками студії.
- `Ctrl + T` — миттєве перемикання світлої / темної теми.
- У вікні OpenCV камери:
  - `ПРОБІЛ` — зняти еталон пози (під час запису жесту).
  - `ESC` або `Q` — вийти / зупинити прев'ю.
