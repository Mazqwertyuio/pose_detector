Модульний конвеєр комп'ютерного зору для розпізнавання людських жестів, поз та міміки в реальному часі через веб-камеру або відеофайл з можливістю підключення користувацьких дій (гарячі клавіші, системні звуки, слайдери гучності тощо).

---

## ✨ Основні можливості

- **⚡ On-Demand AI Architecture**: MediaPipe моделі (Face Landmarker, Hand Landmarker, Pose Landmarker) завантажуються в оперативну пам'ять лише за потреби активних модулів і кешуються локально.
- **🎨 Glassmorphism GUI (Flet)**:
  - Сучасний адаптивний інтерфейс на базі Flutter/Flet (Material 3).
  - Підтримка темної, світлої та системної тем із вибором із 6 акцентних кольорів.
  - Анімовані світлові орбіти, каскадна поява елементів і плавні переходи.
  - **Працює як десктопний додаток або у веб-браузері (`--web`)**.
- **🎯 6 фундаментальних парадигм жестів**:
  1. **Статична поза (Static Pose)** — фіксація форми кисті чи нахилу голови (кулак, знак миру ✌️, палець вгору 👍).
  2. **Траєкторія руху (Spatial Trajectory)** — динамічний просторовий жест (змах рукою, коло, свайп).
  3. **Трансформація (Pose Transition)** — двоетапний жест перетворення однієї пози в іншу (Поза А $\to$ Поза Б із таймером переходу, наприклад *Кулак $\to$ Пальці*).
  4. **Циклічний рух (Periodic Wave)** — махання рукою або похитування головою по горизонтальній чи вертикальній осі.
  5. **Утримання пози (Hold Pose)** — утримання пози протягом визначеного часу (1–5 сек) із заповненням прогрес-бару.
  6. **Аналоговий регулятор (Continuous Slider)** — плавне керування безперервним значенням (0%–100%) за рахунок висоти долоні або щипка пальцями.
- **🔴 Вбудована студія запису жестів (`record_pose.py`)**: запис нових еталонів жестів за 1 клік прямо з камери без написання коду.
- **🧪 Жива перевірка жестів (`test_gesture.py`)**: тестовий запуск окремого жесту з HUD-індикацією, динамічним прогрес-баром та підтвердженням спрацювання.
- **🔌 Модульність Hot-Plug**:
  - `modules/gestures/` — додавання алгоритмічних `.py` модулів або збережених `.json` зразків.
  - `modules/actions/` — дії (емуляція натискання клавіш, звуковий сигнал, HUD-повідомлення).
  - `modules/sources/` — джерела відео (веб-камера, відеофайли).

## 🚀 Швидкий старт

### 1. Клонування та встановлення залежностей

```bash
git clone https://github.com/your-username/vpose-combine.git
cd vpose-combine

# Створення віртуального середовища (рекомендовано)
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/macOS

# Встановлення пакетів
pip install -r requirements.txt
```

> **Примітка:** Моделі MediaPipe (`.task`) автоматично завантажуються в папку `models_cache/` під час першого запуску конвеєра або запису жесту.

---

### 2. Запуск

#### 🖥️ Графічний інтерфейс (Десктоп):
```bash
python flet_app.py
# або
python run.py --gui
```

#### 🌐 Веб-версія у браузері (Web Studio):
```bash
python flet_app.py --web
# або
python run.py --web
```
*За замовчуванням відкривається локальний сервер на `http://localhost:8550`.*

Можна вказати власний порт та хост (наприклад, для доступу з іншого пристрою в локальній мережі):
```bash
python flet_app.py --web --port 8080 --host 0.0.0.0
```

#### 💻 Інтерактивне консольне меню:
```bash
python run.py
```
```text
ГОЛОВНЕ МЕНЮ:
  [1] Запустити розпізнавання (обрати джерело та рухи)
  [2] Записати новий рух / позу з камери (Record Pose)
  [3] Видалити записаний рух (Delete Gesture)
  [4] Запустити збережений пайплайн (pipeline.yaml)
  [5] Запустити графічний інтерфейс Flet (GUI Studio - Десктоп)
  [6] Запустити веб-версію у браузері (Web Studio - Браузер)
  [0] Вихід
```

## 📂 Структура проєкту

```text
├── core/                        # Ядро конвеєра
│   ├── engine.py                # Головний цикл обробки кадрів, дзеркалення, FPS
│   ├── model_manager.py         # Керування моделями MediaPipe Tasks (Lazy Loading)
│   ├── module_loader.py         # Динамічне завантаження модулів .py та .json
│   ├── template_detector.py     # Детектор 6 парадигм жестів за еталонами
│   ├── visualizer.py            # Візуалізація точок скелета, HUD та банерів
│   ├── wizard.py                # Інтерактивний консольний майстер налаштування
│   └── delete_manager.py        # Менеджер видалення зразків жестів
├── modules/
│   ├── gestures/                # Модулі розпізнавання жестів (.py)
│   │   └── recorded/            # Записані зразки жестів (.json)
│   ├── actions/                 # Дії на спрацювання (keyboard_press, sound_beep...)
│   └── sources/                 # Джерела кадрів (webcam, video_file)
├── utils/
│   └── pose_math.py             # Векторна геометрія: кути, нормалізація, відстані
├── flet_app.py                  # Повнофункціональна студія на Flet (Desktop & Web)
├── record_pose.py               # Консольна та інтерактивна утиліта запису жестів
├── test_gesture.py              # Автономний швидкий тест будь-якого жесту наживо
├── run.py                       # Головна точка входу для консолі та меню
├── pipeline.yaml                # Конфігурація збереженого конвеєра
└── requirements.txt             # Залежності проєкту
```

## ⌨️ Гарячі клавіші в додатку

- `Ctrl + 1 ... 5` — швидке перемикання між вкладками студії.
- `Ctrl + T` — миттєве перемикання світлої / темної теми.
- У вікні OpenCV камери:
  - `ПРОБІЛ` — зняти еталон пози (під час запису жесту).
  - `ESC` або `Q` — вийти / зупинити прев'ю.
